# 運用（監視・バックアップ）

[目次に戻る](README.md)

## ログ・監視・エラー通知

- アプリのログは JSON 形式で出力し、CloudWatch Logs に送る。保持期間は 14 日とし、無料枠の範囲に抑える
- CloudWatch アラームを次の条件で設定する
  - 5xx エラーの増加
  - CPU 使用率 80% 超
  - DB 接続数の上限接近
  - ディスク使用率 80% 超
  - ヘルスチェックの失敗
- アラームが鳴ったら、Amazon SNS から管理者にメールで通知する
- AWS Budgets で月額予算のアラートを設定し、想定外の課金に気づけるようにする

## バックアップ

- RDS を使う場合：自動バックアップを有効にし、保持期間は 7 日とする
- EC2 に DB を同居させる場合：毎日 pg_dump でバックアップを取り、S3 に保存する。S3 のライフサイクル設定で 7 日後に自動削除する
- 投稿画像の S3 バケットはバージョニングを有効にし、誤削除に備える
- 公開前に一度、バックアップからの復元手順を実際に試す
