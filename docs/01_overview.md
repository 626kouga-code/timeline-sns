# 概要

[目次に戻る](README.md)

## 概要・目的

X（旧Twitter）のように、短文と画像を時系列で共有できるタイムライン型の SNS を Web アプリとして開発する。講義の課題として個人で開発する。AWS に公開するが、利用者は講義の関係者を想定し、不特定多数向けの運用に必要な機能（荒らし対策・アカウント管理・Google ログインなど）は MVP の対象外とする（[#54](https://github.com/626kouga-code/timeline-sns/issues/54)）。

**MVP のゴール**

- ユーザーが登録・ログインし、テキストと画像を投稿できる
- フォローしたユーザーの投稿がホームタイムラインに新しい順で表示される
- 投稿にいいね・コメント・返信でリアクションでき、その通知を受け取れる
- AWS に公開し、ブラウザから使える

## 前提条件・想定利用者

- 開発・運用は 1 名。利用者は講義の関係者（数人〜数十人）を想定する
- ユーザーが増えても構成を大きく変えずに拡張できる設計にする
- 対応言語は日本語のみ

| ロール | 説明 | できること |
| --- | --- | --- |
| ゲスト（未ログイン） | アカウントを持たない訪問者 | 全体タイムライン・投稿詳細・プロフィールの閲覧、新規登録、ログイン |
| 一般ユーザー | 登録済みの利用者 | 投稿、コメント・返信、いいね、フォロー、ユーザー検索、通知の確認、プロフィール編集 |
| 管理者 | 運営者（開発者本人） | 通報の確認、投稿・コメントの削除、アカウントの凍結・凍結解除（Could。MVP では作らない） |

## リリース計画・スコープ外

1. **MVP**：[機能要件](02_functional-requirements.md)の Must をすべて実装し、公開する
2. **次リリース**：Should（いいね一覧、ミュート）
3. **将来**：Could（リポスト・引用、ハッシュタグ、投稿検索、ブックマークなど）。講義用に MVP から外した、ブロック・通報・管理画面・凍結・メールアドレス確認・パスワードリセット・退会・Google ログイン・レート制限もここに含む

**今回は対象外**

- ダイレクトメッセージ
- 動画投稿
- 投稿の編集
- 非公開（鍵）アカウント
- ネイティブアプリ（iOS / Android）とプッシュ通知
- 多言語対応
