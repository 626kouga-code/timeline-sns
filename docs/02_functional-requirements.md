# 機能要件

[目次に戻る](README.md)

優先度：**Must** = MVP に必須 / **Should** = 次リリース / **Could** = 余裕があれば

## 認証・アカウント

| ID | 機能 | 詳細仕様 | 優先度 |
| --- | --- | --- | --- |
| F-01 | 新規登録 | メールアドレス、パスワード（8 文字以上）、ユーザーID（@handle、英数字と `_`、3〜15 文字、一意）、表示名（50 文字以内）を登録する。利用規約とプライバシーポリシーへの同意を必須にする | Must |
| F-02 | メールアドレス確認 | 登録時に確認リンク（有効期限 24 時間）を送る。確認が済むまで投稿・コメント・いいね・フォローはできない | Must |
| F-03 | ログイン／ログアウト | メール＋パスワードでログインする。ログアウトするとリフレッシュトークンを無効化する | Must |
| F-04 | Google ログイン | Google アカウントでログイン・登録する。確認済みの同じメールアドレスを持つアカウントがあれば、そのアカウントに紐付ける。初回はユーザーIDの設定画面を表示する | Must |
| F-05 | パスワードリセット | 登録メールに再設定リンク（有効期限 1 時間、1 回限り）を送る。再設定すると全端末のリフレッシュトークンを無効化する | Must |
| F-06 | 退会 | 本人確認（パスワード再入力）の後、アカウントと投稿・画像・いいね・フォロー・通知を削除する。返信が付いたコメントは「削除されたユーザー」として本文を消す | Must |

## 投稿

| ID | 機能 | 詳細仕様 | 優先度 |
| --- | --- | --- | --- |
| F-10 | テキスト投稿 | 本文は 1〜280 文字。画像があれば本文なしでも投稿できる | Must |
| F-11 | 画像投稿 | 1 投稿に最大 4 枚。JPEG / PNG / WebP / GIF、1 枚 5MB まで。サーバーで Exif（位置情報など）を除去し、サムネイルを生成する。一覧ではサムネイルを表示し、タップで拡大する | Must |
| F-12 | 投稿削除 | 自分の投稿だけ削除できる。付いていた画像・いいね・コメントも削除する。投稿の編集はできない | Must |
| F-13 | 投稿詳細 | 投稿本文、画像、いいね数、コメント数、コメントスレッドを表示する | Must |
| F-14 | OGP 対応 | 投稿 URL をシェアしたとき、本文の冒頭と 1 枚目の画像がプレビュー表示されるようにする | Must |

## タイムライン

| ID | 機能 | 詳細仕様 | 優先度 |
| --- | --- | --- | --- |
| F-20 | ホームタイムライン | 自分とフォロー中のユーザーの投稿を新しい順に表示する。20 件ずつの無限スクロール。ブロック関係にあるユーザーの投稿は除外する | Must |
| F-21 | 全体タイムライン | 全ユーザーの投稿を新しい順に表示する。未ログイン時のトップ画面にする | Must |
| F-22 | 新着表示 | 表示中の先頭より新しい投稿を 30 秒ごとに確認し、あれば「新しい投稿があります」と表示する。タップで反映する。自分の投稿は数えない | Must |

## いいね・コメント

| ID | 機能 | 詳細仕様 | 優先度 |
| --- | --- | --- | --- |
| F-30 | いいね／取り消し | 1 ユーザーにつき 1 投稿 1 回。いいね数を表示する | Must |
| F-31 | コメント投稿 | 投稿にコメントする。本文は 1〜280 文字 | Must |
| F-32 | 返信 | コメントに返信できる。階層の深さに制限はない。画面では 2 階層目までインデント表示し、それより深い返信は「@ユーザー への返信」と付けて 2 階層目に並べる | Must |
| F-33 | コメント削除 | 自分のコメントだけ削除できる。返信が付いている場合は「このコメントは削除されました」と表示する（論理削除） | Must |
| F-34 | いいね一覧 | プロフィールに「いいねした投稿」を表示する | Should |

## ユーザー・フォロー

| ID | 機能 | 詳細仕様 | 優先度 |
| --- | --- | --- | --- |
| F-40 | プロフィール表示 | アイコン、表示名、ユーザーID、自己紹介、投稿一覧、フォロー数・フォロワー数 | Must |
| F-41 | プロフィール編集 | アイコン画像、表示名、自己紹介（160 文字以内）を変更する | Must |
| F-42 | フォロー／解除 | 他ユーザーをフォローし、ホームタイムラインに反映する。自分自身はフォローできない | Must |
| F-43 | フォロー・フォロワー一覧 | プロフィールからそれぞれの一覧を表示する | Must |
| F-44 | ユーザー検索 | ユーザーIDと表示名で部分一致検索する（大文字小文字は区別しない）。ゲストも使える。凍結ユーザーとブロック関係にあるユーザーは結果から除外する。20 件ずつ表示する | Must |

## 通知

| ID | 機能 | 詳細仕様 | 優先度 |
| --- | --- | --- | --- |
| F-50 | 通知一覧 | 自分の投稿へのいいね・コメント、自分のコメントへの返信、フォローされたことを新しい順に表示する | Must |
| F-51 | 未読バッジ | 未読の通知数をナビゲーションに表示する。通知一覧を開いたら既読にする | Must |

## 安全対策・管理

| ID | 機能 | 詳細仕様 | 優先度 |
| --- | --- | --- | --- |
| F-60 | ブロック | ブロックした相手とは、互いの投稿・コメントが表示されず、フォロー・いいね・コメント・返信もできない。ブロックすると既存のフォロー関係は解除される | Must |
| F-61 | 通報 | 投稿・コメント・ユーザーを、理由（スパム、嫌がらせ、不適切な画像、その他）を付けて通報する | Must |
| F-62 | 管理画面 | 管理者だけが使える。通報一覧の確認、投稿・コメントの削除、アカウントの凍結・凍結解除、対応状況（未対応・対応済み・却下）の管理 | Must |
| F-63 | 凍結 | 凍結されたアカウントはログインできず、投稿・プロフィールは非表示になる | Must |
| F-64 | ミュート | 相手に知られずに、特定ユーザーの投稿を自分のタイムラインから非表示にする | Should |

## 将来の機能（Could）

リポスト・引用、ハッシュタグ、投稿の全文検索、ブックマーク、画像の代替テキスト（alt）、ダークモード、PWA 化。
